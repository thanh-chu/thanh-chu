**Student project for Ericsson, Karlskrona** · Team of 5 · Feb – May 2026 · **Grade A**

A feedback-controlled framework for continuous performance monitoring — detects saturation points, tracks trends, and visualises system health in real time.

- Built a feedback-controlled load-testing framework in Python with Locust
- Automated saturation detection, trend reporting, and history storage in SQLite
- Containerised the system with Docker/Minikube; built live dashboards in Grafana and Prometheus
- Acted as Project Owner for the first and last sprints; contributed code and reviews across nearly all modules
- Delivered every client and academic demo as lead presenter

**Stack:** Python, Locust, Grafana, Prometheus, SQLite, Docker, Minikube, pytest, Cypress, GitLab
